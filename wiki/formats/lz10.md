# LZ10

*Nintendo's “type 0x10” LZ77 compression scheme*

Any file on the disc ending in `.cmp` is compressed with Nintendo's LZ77 variant commonly nicknamed **“type 0x10”** after its header byte — a standard, documented Nintendo scheme used across many GBA/GameCube/Wii titles, not specific to this game. Decompressing a `.cmp` file produces either raw data directly, or — more often in practice — a [pack archive](./pack-archive.md) bundling several files together.

  The scheme is a classic sliding-window compressor. The first byte is `0x10`; the next three bytes store the uncompressed size in little-endian order. The body is divided into groups controlled by a flag byte. A zero flag bit means the next byte is copied literally. A one bit means the next two bytes encode a length of 3–18 bytes and a backward distance of 1–4096 bytes into data already produced.

  Every game resource inside a `.cmp` wrapper — [Pack Archive](./pack-archive.md), [Dispo Format](./dispo-format.md), [Map File Format](./map-format.md), portrait files, `title.cmp`, and `system.cmp` — passes through this layer first.

## How to read an LZ10 stream

  Read the declared output size, then consume each flag byte from its highest bit to its lowest. Literal tokens append one source byte. Back-reference tokens copy from the output already produced and may overlap their own destination, which is how a short pattern expands into a longer run. Stop when the declared output size has been produced; archive boundaries belong to the decompressed payload, not to LZ10.

## Example and common pitfall

  If a back-reference says “copy 6 bytes from 3 bytes behind,” the decoder repeats the preceding three-byte pattern twice because copying proceeds one output byte at a time. Do not decode the distance against the compressed input position, and do not assume every decompressed result is a pack archive—portraits can expand directly to TPL data.

## Known limits

The compression format itself is complete. What follows it must be identified from the decompressed payload's magic or expected resource path.
