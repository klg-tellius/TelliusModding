# Tutorial capture log

This page is written by `App/tools/capture_tutorial_screenshots.py` from `wiki/assets/images/tutorials/screenshots/capture_log.json`; edit the tool, not the page. It records the [capture plan](tutorial-screenshot-plan.md)'s frames: the ones taken, where each one is used, and the ones still to take.

Every frame was taken by the tool from the real app on a disposable *Tutorial Practice* project (fresh USA extraction), in the app's default dark theme. A captured frame shows the app state named in its caption; it is not evidence of in-game behaviour. Frames from lessons 65 and above illustrate tutorials that the [2026-10-20 review](tutorial-coverage.md#review-2026-10-20) adds and that are not written yet.

**182 frames captured; 73 of the plan's 159 required frames still to take.**
