# Maps and assets learning path

Visual files are selected by data tables and scripts. Learn the lookup path before replacing an image or model so the edited resource is actually loaded.

## Route

1. [Maps](../systems/maps-system.md), [Map File Format](../formats/map-format.md), and [Map Objects](../systems/map-objects.md)
2. [Terrain Texture Blending](../systems/terrain-texture-rendering.md) and [TPL Texture](../formats/tpl-texture.md)
3. [Graphics & Images](../systems/graphics-system.md), [Face Data](../formats/face-data.md), and [Rect.bin](../formats/rect-format.md)
4. [Music](../systems/music-system.md), [MusyX](../formats/musyx.md), and [STM](../formats/stm-format.md)
5. [THP](../formats/thp-format.md) and [Cutscenes](../systems/cutscenes.md)

Preserve palette, dimension, mipmap, archive-priority, and file-size constraints called out by each format article.
