# Create a chapter learning path

A chapter is a coordinated set of records and files rather than one map file. Build it in layers and test after each layer.

## Route

1. [Chapters](../systems/chapters.md) and [Objectives](../systems/objectives.md)
2. [Maps](../systems/maps-system.md), [Coordinate Systems](../systems/map-grid.md), and [Map Objects](../systems/map-objects.md)
3. [Dispo Format](../formats/dispo-format.md) for deployed units and groups
4. [Events & Scripting](../systems/events-scripting.md) and [Event Flags](../systems/event-flags.md)
5. [Message Format](../formats/message-format.md) for dialogue
6. AI behavior in [`cp_data.bin`](../formats/cp-data-format.md)

Validate terrain bounds, spawn tiles, objectives, progression, flags, and every difficulty variant before adding presentation polish.
